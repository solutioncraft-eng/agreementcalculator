## What can be branded

Agreement Calculator has one house style; each workspace layers its own identity on top:

| Setting | Where it appears |
| --- | --- |
| **Logo** | The application header and the top of every PDF |
| **Accent colour** | Buttons, highlights and links throughout the application, and accents in the PDFs |
| **PDF footer** | The footer line of the agreement PDF — typically company name, address and registration details |
| **Offering names** | Everywhere an offering is shown, including PDFs — set per pricing version, not here |

A workspace with no logo shows its name instead.

## Changing branding

:::role ADMIN
Open **Settings → Branding**.

- **Logo** — upload an image, or paste the URL of an image you host. Uploads need object storage to be configured for your deployment; if the upload option is unavailable, use a URL.
- **Accent colour** — pick a colour. If it is too light to carry white text the application automatically uses navy text on it.
- **PDF footer** — the text printed at the foot of client documents.

Save. The change applies to every member immediately and is written to the audit log.
:::

## Renaming offerings

Offering names are part of the pricing version because they must stay stable on every historical quote and PDF. To rename one, create a draft under **Settings → Pricing**, edit the offering, and publish — see [COGS catalogue and offerings](/help/guide/cogs-and-offerings).
