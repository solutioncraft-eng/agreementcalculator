## Terms

| Term | Meaning |
| --- | --- |
| **Account manager (AM)** | A member who prices agreements, exports in-policy PDFs and submits flagged quotes for review. |
| **Add-on multiplier / add-on markup** | The lever applied to the tool cost of items an offering adds on top of its parent offering. |
| **Agreement PDF** | The client-facing document: offering, per-user rate, monthly total, bundle, branding. |
| **Agreement rate** | The per-user monthly sell price for an offering. |
| **Approval** | A leader's decision that unlocks PDF export for a flagged quote at exactly the submitted numbers. |
| **Archived version** | A previously published pricing version, replaced by a newer publish. Still referenced by old quotes and exports. |
| **Audit log** | The append-only record of every significant action in the workspace. |
| **Bundle discount** | A named percentage off the agreement rate for clients taking more than one service. Never sells below cost. |
| **COGS item** | Cost of goods sold: a tool or licence you pay for, with a unit cost and unit basis. |
| **Cost basis** | A short description on a pricing version of where its costs came from; printed on PDFs. |
| **Co-managed** | An offering delivered alongside the client's own IT staff. Its base tools are priced with the version's co-managed labor multiplier or co-managed markup instead of the fully managed lever; offerings built on it are co-managed too. |
| **Cost floor** | The lowest a rate can go: tool + imputed labor on cost-plus, raw tool cost on markup. |
| **Cost-plus** | The pricing model that solves the rate from cost and a target service gross margin. |
| **Draft** | An editable pricing version that the Calculator does not yet use. |
| **Export ID** | The identifier stamped on every PDF and recorded in the export registry. |
| **Export registry** | The list of every generated PDF with its checksum and reproduction inputs. |
| **Flagged** | A quote that departs from published policy and therefore needs leadership review before export. |
| **Floor override** | The Calculator option that shows a true below-floor rate instead of applying the floor. Always flagged. |
| **Internal COGS PDF** | The confidential worksheet showing every cost, the lever applied and the achieved margin. |
| **Labor multiplier** | On cost-plus, imputed labor as a multiple of tool cost. |
| **Leader** | A member who can approve, recommend changes on, deny and comment on quotes. |
| **Markup multiple** | The pricing model that sells at a multiple of tool cost. |
| **Membership** | A person's place in a workspace, carrying their role there. |
| **Offering** | An agreement product you sell, built from COGS items; may stand alone or build on a parent offering. |
| **Operator** | Someone who runs the Agreement Calculator service and manages workspaces from outside them. |
| **Per-offering floor** | A per-user floor set on one offering — lower than the version's, or 0 for none — so a co-managed offering is not lifted to a fully managed floor. The cost floor still applies. |
| **Per-user floor** | The minimum per-user rate; the floor is charged when the calculated rate is lower. |
| **Pricing model** | Cost-plus or markup multiple; one per workspace. |
| **Pricing version** | A snapshot of settings, offerings, COGS items and bundles. Draft, published or archived. |
| **Published version** | The one immutable version the Calculator currently prices against. |
| **Quote (quote request)** | A calculation that was submitted for review, with its inputs, pinned version, rates and thread. |
| **Reference (QR-…)** | A quote request's identifier, e.g. `QR-2026-09-3F2A`. |
| **Retention** | How long submitted quotes are kept before being purged (12 months by default). |
| **Service gross margin (SGM)** | On cost-plus, the target margin the rate is solved for. |
| **Stamp** | The line on every PDF page with export ID, time, build, pricing version and approval state. |
| **Tool cost** | The sum of an offering's active COGS items for the quoted environment. |
| **Trigger** | A specific reason a quote is flagged, listed in the Calculator's results panel. |
| **Unit basis** | Whether a COGS item is priced per user, per device, per location or flat per agreement. |
| **Workspace** | One company's private instance: people, pricing, quotes, audit log. |
